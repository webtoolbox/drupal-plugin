INTRODUCTION
------------

Welcome to WebsiteToolbox Forums. Please see the advanced help for more information.

If you're having trouble installing this module, please ensure that your tar
program is not flattening the directory tree, truncating filenames or losing
files.


 

INSTALLATION
------------

Install as you would normally install a contributed Drupal module. See:
https://drupal.org/documentation/install/modules-themes/modules-7 for further
information.

Navigate to administer >> modules. Enable WebsiteToolbox Forums.
